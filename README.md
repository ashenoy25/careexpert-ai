# CareExpert AI

**Evidence-based caregiving assistant by MeetCaregivers**

An AI-powered tool that provides caregivers with instant, evidence-based guidance grounded in clinical guidelines from NIH, CDC, CMS, AHA, ADA, Alzheimer's Association, and 15+ more leading health organizations.

## Features

- **Evidence-based answers** across 16 clinical caregiving domains
- **Source transparency** — every answer cites the guidelines and research it drew from
- **Safety-first triage** — clearly indicates when to call 911, contact a nurse, or what caregivers can handle
- **Scope of practice** guardrails aligned with CMS HHA requirements (42 CFR 484.80)
- **21 curated source documents** from peer-reviewed literature, clinical guidelines, federal standards, and professional training programs

## Who It's For

- **Home Health Aides & CNAs** — quick, reliable answers during a shift
- **Family Caregivers** — navigating dementia, chronic illness, and daily care
- **Care Managers** — reference for guidelines, training, and best practices

## Running Locally

```bash
pip install -r requirements.txt
# Add your Anthropic API key to .streamlit/secrets.toml
streamlit run app.py
```
